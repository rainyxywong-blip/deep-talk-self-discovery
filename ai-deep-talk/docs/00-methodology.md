# 方法论：把自我认识变成可修正的研究过程

## 1. 基本命题

人对自己的认识通常混合了事实、记忆、解释、他人评价和身份标签。AI 又特别擅长把零散材料组织成连贯故事，因此“听起来准确”并不等于真实。

AI Deep Talk 使用一条严格路径：

> 具体事实 → 行为过程 → 当时体验 → 动机假设 → 跨事件比较 → 现实验证

## 2. 六条原则

### 事实优先

先问何时、何地、谁参与、发生了什么、你做了什么，再讨论意义。

### 观察不等于结论

“三个事件中都推迟提交”是观察；“我是拖延的人”是标签。系统保留前者，谨慎处理后者。

### 单个事件不能定义一个人

形成模式前至少比较 2–3 个事件，并主动寻找例外。

### 动机通常不唯一

同一行为可以同时满足安全、归属、成就、控制、休息等需求。不要强求一个“终极根源”。

### 假设必须可证伪

好的假设包含触发情境、可观察行为、可能需求、短期收益、长期代价和反例条件。

### 现实拥有最终解释权

AI 输出只是候选解释。新事件和现实实验可以修正或推翻旧假设。

## 3. 证据等级

| 等级 | 内容 | 使用方式 |
|---|---|---|
| E0 | AI 的联想或泛化 | 不进入结论 |
| E1 | 单次回忆、自我描述 | 记录为线索 |
| E2 | 具体事件与行为细节 | 可支持低置信度观察 |
| E3 | 多个独立事件出现相似结构 | 可形成待验证模式 |
| E4 | 现实实验或同期记录支持 | 可提高置信度 |
| E5 | 持续出现且有反例边界 | 可暂时纳入个人模型 |

记忆并非录像。即便叙述很具体，也应标注“依据回忆”，不要伪装成客观记录。

## 4. 三种输出状态

- **已确认事实**：使用者确认发生过的事件和行为；
- **暂定观察**：材料中可见的差异、重复或矛盾；
- **待验证假设**：对触发条件、需求和行为倾向的解释。

AI 每次总结都必须保持这三类分离。

## 5. 完成标准

系统没有“最终看透自己”的完成状态。一轮研究完成，是指：

1. 一个研究问题被具体化；
2. 至少一个事件得到可靠还原；
3. 形成了有限、带条件的观察；
4. 观察被改写为可验证假设；
5. 下一步现实实验足够小且安全；
6. 使用者知道何时复盘以及如何更新。
