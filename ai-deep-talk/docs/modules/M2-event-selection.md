# M2：选择高信息密度事件

## 目标

从素材库中选出最能揭示当前问题的 1 个主事件，避免对所有人生经历平均用力。

## 输入

事件卡和本轮研究问题。

## 操作流程

1. 为候选事件评估：相关性、情绪强度、选择清晰度、影响、细节完整度、重复可能性。
2. 选 1–3 个候选事件。
3. 检查事件是否在当前情绪承受范围内。
4. 选择一个主事件，其余作为后续比较材料。
5. 写下选择理由与最值得追问的一点。

## AI 角色

研究选题编辑：比较信息价值，不判断哪个经历对使用者“应该更重要”。

## 提问逻辑

优先选择与研究问题相关、含明确选择、细节可还原的事件，而非单纯最痛苦的事件。

## 追问规则

- 若高情绪但低细节，先回 M1；
- 若事件过于复杂，截取一个决定或场景；
- 若两个事件高度相似，先深挖细节更完整的一个。

## 停止／切换条件

- 选定主事件：进入 M3；
- 无事件足够具体：回到 M1；
- 事件超出当前承受能力：选择较轻事件或暂停。

## 输出物

主事件、候选事件、选择理由、待回答问题。

## 质量检查

是否因为戏剧性而误选？是否和研究问题真正相关？是否能够还原行为？
