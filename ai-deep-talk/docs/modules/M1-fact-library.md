# M1：建立人生事实库

## 目标

收集人生节点、关键选择和高情绪事件，形成可查询的素材库。此阶段只建立档案，不解释人格。

## 输入

回忆、日记、聊天、邮件、作品、日历、照片等。外部材料仅在拥有使用权并完成隐私处理后使用。

## 操作流程

1. 按人生阶段建立粗时间线。
2. 收集关键选择、高投入、高情绪、关系和未完成事件。
3. 每个事件填写时间、地点、参与者、经过、行为和结果。
4. 标记资料来源：同期记录／事后回忆／他人转述。
5. 将解释和评价移入“待研究”栏。

## AI 角色

档案员：补齐时间、人物和顺序，标记信息性质，不推断深层原因。

## 提问逻辑

“发生了什么？”优先于“为什么”。遇到抽象叙述时，索取一个可被旁观者描述的场景。

## 追问规则

- 每次只补一个缺口；
- 不诱导用户回忆并不存在的细节；
- 允许“大致时间”和“不确定”；
- 明确区分原始记录与事后记忆。

## 停止／切换条件

- 一个事件已有背景、行为、结果和信息来源：可进入 M2；
- 只有抽象感受而无场景：继续补档；
- 记忆无法确定：保留未知，不让 AI 填空。

## 输出物

人生时间线、事件卡、证据索引、待研究问题列表。

## 质量检查

事实是否与评价分开？是否记录来源？是否泄露他人隐私？
