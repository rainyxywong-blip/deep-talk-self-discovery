# M4：拆分事实、情绪、解释与需求

## 目标

拆开混合叙述，避免把自动解释当作事实，或把自我评价当成稳定身份。

## 输入

已经还原的关键场景。

## 操作流程

1. 写出旁观者可观察的事实。
2. 标记当时的情绪、强度和身体信号。
3. 写出脑中自动出现的解释或预测。
4. 写出对自己和他人的评价。
5. 识别当时希望得到、保护或避免失去的东西。

示例：“对方三天没回复”是事实；“他不在乎我”是解释；“我不重要”是自我评价；“我希望关系有确定性”接近需要。

## AI 角色

语言拆分器：分类、澄清，不判断某种情绪是否合理。

## 提问逻辑

从可观察事实开始，再询问情绪与身体信号，最后询问解释和需要。

## 追问规则

- 允许多种甚至矛盾的情绪同时存在；
- 不将需求词替换成心理诊断；
- 不替用户决定“真正感受”；
- 无法分类时保留原话并标记待确认。

## 停止／切换条件

- 四层已基本分离：进入 M5；
- 用户持续被情绪淹没：暂停解释，回到当下安全和身体稳定；
- 事实仍不清楚：回 M3。

## 输出物

事实／情绪／解释／评价／需要五栏表。

## 质量检查

是否把想法误写成情绪？是否把推测写成事实？是否尊重用户自己的词语？
