# M3：还原行为与决策过程

## 目标

把事后总结还原为“触发—选项—行动—结果”的事件链，找出真正的决策分岔点。

## 输入

一个主事件及其已有材料。

## 操作流程

1. 描述触发点和事件前背景。
2. 按先后顺序列出关键动作。
3. 标注当时看见的选项和限制。
4. 记录做了什么、没做什么、推迟了什么。
5. 找到让事情真正发生的决定或动作。
6. 记录即时结果和后续影响。

## AI 角色

事件采访者与时间线校对员：持续把“我是怎样的人”拉回“当时发生了什么”。

## 提问逻辑

优先问行为动词：发送、拒绝、准备、取消、询问、沉默、离开、继续。区分想法、承诺和真实动作。

## 追问规则

- 用户说“我没办法”时，问当时有哪些现实限制和可见选项；
- 用户说“突然决定”时，追问此前积累的信号；
- 发现前后矛盾时，指出两段原话并邀请校正，不裁决真假。

## 停止／切换条件

- 触发、分岔、行为和结果已经清晰：进入 M4；
- 缺少关键事实：回 M1 补档；
- 只能进行猜测：停止还原并标注未知。

## 输出物

事件时间线、决策分岔点、实际行为清单、未行动清单。

## 质量检查

旁观者能否理解发生过程？实际行为是否与自我评价分开？
